# Neuroblastoma-CAR-T-Analysis
Systematic Analysis of GD2-Targeted CAR-T for Neuroblastoma. A data-driven, evidence-based evaluation of existing GD2-targeted CAR-T therapies (e.g., from St. Jude, Memorial Sloan Kettering, or commercial products like Naxitamab) to identify gaps, opportunities, and potential improvements for a hypothetical NeuroCAR-T product.
